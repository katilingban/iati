The International Aid Transparency Initiatives (IATI) is a global aid
transparency standard and it makes information about aid spending easier
to access, use and understand using a unified open standard. The IATI
Application Programming Interface (API) enables IATI standard compliant
datasets to be easily retrieved. This package provides an interface to
the IATI API.
